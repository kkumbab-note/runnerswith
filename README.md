# 러너스위드 Runners With

당신과 함께 달리는 일상을 위한 기어 — 러닝화·러닝 의류·러닝 장비 브랜드 원페이지 사이트.

- 사이트: https://kkumbab-note.github.io/runnerswith/
- 단일 `index.html` (HTML + CSS + 바닐라 JS), 이미지·로고·영상은 `assets/`
- 제품 상세 갤러리와 3D 보기(Three.js, 상세 모달의 3D 탭을 열 때만 로드)
- 판매 채널 URL·연락처는 `index.html` 하단 스크립트의 `CONFIG`에서 바꿔요

> 제품·라이프스타일 사진과 히어로 영상은 AI로 만든 가상 이미지예요. 실제 판매 전에 실제 촬영본으로 교체해 주세요.
